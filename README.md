# 📚 BookAura

BookAura is a simple and responsive online bookstore website built using **HTML, CSS, and JavaScript**. Users can browse books, search for titles, add books to the cart, and view their selected items.

## ✨ Features

* Responsive design
* Book listing
* Search functionality
* Add to Cart
* Shopping Cart page
* Dark/Light mode

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Google Fonts
* Font Awesome

## 📚 Books Included

* The Psychology of Money
* The Silent Patient
* Ikigai
* Deep Work
* Rich Dad Poor Dad
* Wings of Fire
* Think Like a Monk
